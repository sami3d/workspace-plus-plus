Workspace++ 1.3.4 hardens release signing and adds favourite-app controls for Raycast.

- Pins the existing certificate/private key by exact fingerprint. No release or source-install script generates a new certificate automatically.
- Preserves `com.saint.SpaceRenamer` and the existing designated requirement, verifies both architecture slices and the native helper, and blocks publication without matching old/new requirements and positive before/after AX trust evidence.
- Adds **Preferences → Raycast Apps** to add/remove installed apps, choose a custom command name, and select New window or New app instance.
- Adds **New App Window** to the bundled Raycast pack, now 14 commands. The saved favourite list is available while Workspace++ is closed. Existing preset commands remain intact.

For custom commands directly in Raycast root search and per-command hotkeys, add the favourite-command directory once; Preferences can reveal it. App capabilities vary: a New window command needs a suitable File menu; a new instance needs that app to support separate instances.

The self-signed certificate/private key backup is protected and kept outside Git. Only release builders need that identity; users installing the official ZIP do not. Developer ID/notarization migration is prepared but not activated because the owner has no Developer ID identity or notarization credentials. This release remains self-signed and not Apple-notarized. The first switch to Developer ID will change the old self-signed requirement and may require one Accessibility reapproval.

Validation: all GitHub checks passed, including signing-policy negative tests, core tests on macOS 14 and 15, app build, and Raycast lint/build/bundle. Both app architectures built locally. A diagnostic-capable 1.3.3-labelled baseline using the existing approved identity and the 1.3.4 candidate both returned AXIsProcessTrusted() = true, with no permission reset or prompt and identical designated requirements. The unmodified published 1.3.3 binary lacks the reporting flag. UI checks covered adding, renaming and removing a favourite and reading it from Raycast with Workspace++ closed; generic window behaviour is dependent on the target app.
