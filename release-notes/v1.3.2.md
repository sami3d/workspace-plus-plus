Workspace++ 1.3.2 makes switching between distant workspaces much faster.

- Replaces paced Control+arrow traversal with high-velocity native Space gestures, supporting more than nine desktops and multiple displays.
- Automatically upgrades the old arrow-switching preference. Leave “Use legacy Ctrl+digit shortcuts” unchecked for fast switching.
- Prefers the modern WindowServer placement API when moving windows, while retaining destination verification and a drag fallback.
- Includes the focused-window movement and picker fixes from 1.3.1.

Local checks on macOS 26.5.2 reached Desktop 21 from Desktop 7 in 328 ms and returned in 249 ms, including request handling. State sampling observed only source and destination; visual transition timing and real application window movement were not verified through UI automation.

The ZIP contains a universal Apple silicon/Intel app and bundled Chrome host for macOS 13 or later. It is self-signed and not Apple-notarized. Existing workspace settings are preserved when replacing the app. See [installation instructions](https://github.com/sami3d/workspace-plus-plus/blob/main/INSTALL.md).

Fast switching uses undocumented macOS gesture fields and may require changes after future macOS updates. If a window rejects direct placement, its drag fallback can still visit the destination and return.
