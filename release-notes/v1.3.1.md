Workspace++ 1.3.1 updates focused-window movement.

- Moves the captured window by its WindowServer ID, with title-bar dragging as a fallback.
- Checks the window's actual workspace before reporting success.
- Adds explicit **Move** and **Move & Follow** buttons.
- Prevents choosing the window's source workspace as its destination.
- Avoids tabs and toolbar controls when choosing a fallback drag point.

Installation:

1. Download and expand `Workspace++-1.3.1-macOS.zip`.
2. Quit Workspace++ if it is running, then move `Workspace++.app` to Applications.
3. Right-click the app and choose **Open** on first launch.
4. Enable Workspace++ under **System Settings → Privacy & Security → Accessibility**.

The app and bundled Chrome native host support both Apple silicon and Intel Macs running macOS 13 or later. The build is self-signed and not Apple-notarized. Existing workspace names, categories, preferences, and cloud data are preserved during upgrades.

Validation: local app compilation for both architectures, code-signature and archive checks, plus passing GitHub CI for the app build, core tests on macOS 14 and 15, and the Raycast extension. Live focused-window movement has not been verified on another Mac.
