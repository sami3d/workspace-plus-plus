Workspace++ 1.3.0 adds the cloud Workspace Library and portable workspace
sessions.

Highlights:

- Save app, window, and Chrome tab history to a Workspace++ cloud account
- Review running and parked workspaces by Mac and date
- Launch, duplicate, park, copy, or move cloud workspaces between Macs
- Bundled Chrome companion and native bridge for tabs, pinned state, and tab groups
- Reconciliation of deleted local Spaces without deleting another Mac's history
- Improved long menu-bar names and external-display positioning

Installation:

1. Download and expand `Workspace++-1.3.0-macOS.zip`.
2. Move `Workspace++.app` to Applications.
3. Right-click the app and choose **Open** on first launch.
4. Grant Accessibility access when prompted.
5. For Chrome session capture, choose **Enable Chrome Integration** in Workspace Library and approve the bundled extension once.

The app and Chrome native host are universal binaries for Apple silicon and
Intel Macs. Existing workspace names, categories, preferences, and cloud data
remain outside the app bundle and are preserved during upgrades.
