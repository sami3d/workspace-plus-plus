Workspace++ 1.2.0 packages workspace-management improvements into a
downloadable macOS app—no Xcode installation is required.

Highlights:

- Workspace categories with editable names and colours
- Optional Workspace++ cloud sync for names, categories, colours, monitor placement, and workspace order
- Compact per-Space app icons with selectable alignment, sorting, and window-count presentation
- Improved multi-display menu-bar naming and Mission Control labels
- Direct named-Space switching and focused-window movement

The app is universal (`arm64` and `x86_64`), self-signed, and not
Apple-notarized. Existing workspace names, categories, preferences, and cloud
data remain outside the app bundle and are preserved during upgrades.
