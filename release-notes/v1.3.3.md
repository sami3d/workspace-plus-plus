Workspace++ 1.3.3 bundles the full Raycast command pack.

- Includes Switch Space, Switch Workspace Picker, Move Window, and all ten New Window commands: Chrome, Helium, Claude, Figma, ChatGPT, Granola, Notion, Finder, TickTick, and Projects.
- First launch opens Raycast's native folder importer with prebuilt commands. No Node.js, npm, Xcode, or source checkout is needed on the receiving Mac.
- If Raycast is installed later, launching it while Workspace++ is running triggers setup. Preferences → Install Raycast Commands retries a cancelled import.
- Removes machine-specific home paths from app-window scripts and includes their shared helper.
- Includes portable Script Commands for older Raycast installations, alongside the live workspace-name scripts.
- Retains the fast switching and window-movement fixes in 1.3.2.

Raycast may require sign-in or import approval once. macOS Accessibility and Automation permissions and Raycast hotkeys are configured per Mac. Each New Window command requires its target app; Projects New requires a synced local Google Drive _Projects/2026 folder. Direct workspace-name Root Search requires adding the generated workspace script directory once; Switch Space works from the imported pack.

The universal app and Chrome host support Apple silicon and Intel with macOS 13+. The Raycast pack was tested with Raycast 2.8; older Raycast versions can use the exported scripts if incompatible. The app is self-signed and not Apple-notarized.

Live checks verified importing the prebuilt folder, workspace search, opening the native switch picker, and Finder New. The other app-window commands were packaged and checked for portability; they were not each run on another Mac.
